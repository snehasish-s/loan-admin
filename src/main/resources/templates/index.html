Project Overview

This system empowers Bank Officers to monitor and approve beneficiary loan utilization efficiently. Beneficiaries submit geo-tagged photos/videos via a mobile app. AI-assisted fraud detection helps validate submissions, and officers can approve or reject transactions with real-time wallet updates. Disclaimer: This demo is strictly for educational and demonstration purposes. We do not intend to hack or compromise any website. The application showcased here is a local project, and you can find the full source code on our GitHub repository for review.
